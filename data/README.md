# Reviewed data / 已审核数据

The five JSONL files are intentionally empty at initialization. Only human-reviewed,
source-backed records with compatible reuse rights belong here. `approved` records
are exported; `deprecated` records retain IDs and provenance but are excluded.
See [the contribution guide](../CONTRIBUTING.md) before adding records.

初始化的五个 JSONL 文件有意保持为空。这里仅接收人工审核、来源可验证且
权利兼容的正式记录。`approved` 参与构建；`deprecated` 保留 ID 和溯源信息，
但不导出。空文件是有效数据集，不应添加占位行。
